# Digital Electronics & VLSI Internship Projects

## 📌 Overview

This repository contains two **Digital Electronics and VLSI internship projects** developed using **Verilog HDL** and simulated using **Xilinx Vivado 2025.2**.

The projects demonstrate fundamental concepts of **digital logic design, Finite State Machines (FSM), RTL design, serial communication, and hardware verification**.

---

## 🚀 Projects

### 🔹 Project 1 – FPGA-Based Traffic Light Controller with Priority System

A Verilog-based traffic light controller designed using a **Finite State Machine (FSM)**.

#### Key Features

- Red, Green, and Yellow traffic light control
- FSM-based state transitions
- Emergency vehicle priority
- Reset functionality
- Verilog RTL implementation
- Verilog testbench verification
- Vivado behavioral simulation

📁 **Project Folder:**

`Project-1-Traffic-Light-Controller/`

---

### 🔹 Project 2 – UART Transmitter (TX) Using Verilog HDL

An 8-bit UART transmitter that converts parallel data into a serial UART data stream.

#### Key Features

- 8-bit parallel data input
- Start bit generation
- 8-bit data transmission
- LSB-first transmission
- Stop bit generation
- FSM-based control
- `tx_busy` status indication
- Verilog testbench verification
- Vivado behavioral simulation

> **Note:** This project implements the **UART Transmitter (TX) only**. UART Receiver (RX) is not included.

📁 **Project Folder:**

`Project-2-UART-Transmitter/`
